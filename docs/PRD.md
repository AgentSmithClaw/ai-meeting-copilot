# PRD - AI Meeting Copilot for Business Teams

## 1. 背景
企业会议常见问题：
- 会中记录零散
- 纪要格式不统一
- 行动项容易遗漏
- 负责人和截止时间不清晰
- 历史会议难检索

## 2. 目标
将会议原始记录转为结构化信息，降低整理成本，提升会后执行和跟踪效率。

## 3. 目标用户
- 项目经理
- 产品经理
- 业务分析师
- 研究助理
- 跨部门协作团队成员

## 4. 核心场景
1. 项目周会
2. 需求评审会
3. 跨部门协调会
4. 专题讨论会

## 5. MVP 功能需求
### 5.1 输入会议内容
字段：
- 会议标题
- 会议日期
- 参会人
- 原始会议记录

### 5.2 自动生成结构化纪要
输出：
- 会议摘要
- 关键结论
- 行动项
- 风险与待确认事项
- 下一步安排

### 5.3 行动项结构化
每条行动项包含：
- 任务名称
- 负责人
- 截止日期
- 状态（默认未完成）

### 5.4 历史记录
- 查看历史纪要
- 支持按关键词搜索

### 5.5 导出
- 支持复制/导出 Markdown

## 6. 非功能需求
- 输出结构稳定
- 页面简洁
- 生成时间控制在可接受范围
- 历史数据本地可保存

## 7. 成功标准
- 能稳定生成结构化纪要
- 能提取大部分行动项
- 可在面试中演示完整闭环

## 8. V2 方向
- 音频转文字
- 周度行动项汇总
- 逾期提醒
- 飞书/企业微信通知
